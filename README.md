# Finixcode Assignment – React/Next.js UI Implementation

This project is a frontend assignment for **Finixcode**, built with **Next.js**, **TypeScript**, and **Tailwind CSS**. The task demonstrates the implementation of modular and reusable components, including a custom modal, a styled date picker using `useRef`,

---

## 🚀 Getting Started


1. Clone the Repository

```bash
git clone https://github.com/Rejaul-arim-shohag/finixcode.git
cd finixcode

2. Install Dependencies
Using Yarn:
yarn install
Using NPM:
npm install

3.Run the Development Server
yarn dev
npm run dev


Visit http://localhost:3000 to view the app in the browser.


Build for Production
yarn build
yarn start
